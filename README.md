# Shapes Manager App
A Python application to create, store, view, filter, and draw different geometric shapes with customizable properties using turtle graphics.
## Features
- Add and store different shapes with properties like size, color, and type
- View all stored shapes or filter them by type or color
- Draw selected shapes visually using Python's turtle graphics
- Get statistics of specified shapes, like their counts and areas
- Simple text-based menu interface for user interaction
## Requirements
- Python 3.x
- `turtle` (included in standard Python library)
## How to use:
- Run the `test.py` file
- Follow the menus!
